# Branding KAPi & KaM·in

Arbeitsstand September 2026. Übersicht als Seite: `markenwelt.html` (im Browser öffnen).

- `brief.md` – Branding-Brief (Ausgangslage, Charakter, Anforderungen)
- `markenstimme.md` – Markenkern, Claim, Tonalität, fertige Textbausteine (Website, Aushang, Instagram, dreisprachig)
- `bildsprache.md` – Fotoregeln, Motivliste für den ersten Fototermin, Do/Don't, Einverständnis-Vorlage
- `palette.json` – Farbwelt: je Logofarbe Pastell, sehr hell, Tint, dunkle Textfarbe (AA-geprüft)
- `logos/` – drei Logo-Richtungen als SVG (Bildmarke, KAPi-Lockup, KaM·in-Lockup, einfarbig, invers, gestapelt) mit je einer Beschreibung (`ring.md`, `punkte.md`, `tor.md`); `claim-handschrift.svg` ist der nachgezeichnete Claim

Empfehlung der Jury: Richtung **Ring**. Vor der Freigabe: Ähnlichkeitsprüfung mit Logos von Gemeinde, Landkreis und Nachbarinitiativen.
